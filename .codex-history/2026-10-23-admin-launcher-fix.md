# Исправление запуска панели в Windows

Дата: 23 октября 2026 года.

Пользователь сообщил, что вместо редактора появляется «Press any key to continue». Ошибка воспроизведена именно запуском CMD: Windows некорректно разбирал строки UTF-8/LF с русским текстом внутри командного файла. Предыдущие проверки запускали Node.js напрямую и не обнаружили проблему.

В `Управление меню.cmd` служебные команды и сообщения переведены в ASCII, установлены Windows-переносы CRLF, добавлен прямой поиск установленного Node.js в Program Files на случай устаревшего PATH Проводника. `.gitattributes` закрепляет CRLF для командных файлов после восстановления из Git.

Добавлен `tests/admin-launcher.test.cjs`: запускает реальный CMD с ограниченным PATH, проверяет доступность панели и закрытый без ключа API, затем останавливает только созданное тестом дерево процессов. До исправления воспроизводилась ошибка; после исправления тест проходит. Данные меню и опубликованный сайт не менялись.
