# Готовая локальная панель Chilli

Дата: 23 октября 2026 года.

Добавлена панель управления меню, запускаемая файлом `Управление меню.cmd`. Можно менять цены, название, подпись, категорию, порядок, видимость и популярность товара, добавлять и удалять товары, загружать фото. Сохранение и публикация разделены; есть предпросмотр. Фото преобразуются в WebP без искажения пропорций.

Рабочие данные: `menu.json`, производный файл сайта: `menu-data.js`. Логика панели: `admin/`, проверки: `tests/admin-*`. Google-таблица не является автоматическим источником после этого перехода. Отдельная инструкция: `admin/README.md`.

Восстановление до переноса: локальный commit `6657a7c7`. После переноса: `62ff5480`. Код панели: `9b40334d` с последующей коррекцией проверки HTTP-кодировки. Публикация сайта: `12557aac79403cc4609829886ea9011d8003c6cf` в main удаленного репозитория shaurma-chilli.

Подтверждено: 54 исходных товара, цены и пути фото сохранены точно. Автотесты хранилища, HTTP и Git: 16/16. Браузерная проверка: изменение цены и перезагрузка, новые категории/товары, фото, специальные символы, скрытие, предпросмотр, восстановление опроса и различение опубликованной/новой версии. Desktop/mobile без горизонтального переполнения. Старая кэшированная страница корректно подгружает новые данные.

Два одновременных запуска main-сервиса проверены: разные свободные порты, HTTP 200 для страницы, HTTP 403 для API без ключа. Тестовые процессы остановлены. Независимый обзор выполнен; все 8 находок исправлены. Реальная публикация через новый механизм прошла, содержимое menu-data.js/index.html/script.js на сайте проверено. При проверке учитывается UTF-8 BOM, удаляемый HTTP-декодером.

Служебные данные, ключи сеанса и временные файлы не включены в Git. Основная ветка сайта не содержит `admin/`; исходники редактора сохраняются отдельно в ветке `codex/local-menu-admin` удаленного репозитория для восстановления.
